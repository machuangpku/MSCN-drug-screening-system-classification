# MSCN Drug Screening System Classification

This project provides a classification implementation for the **MSCN Drug Screening System**.

## Usage

Run the following command in the project directory:

```bash
python MSCN-drug-screening-system-classification.py
```

## Project Structure

```text
MSCN-drug-screening-system-classification.py
```

## Requirements

Make sure Python and the required dependencies are installed before running the program.
